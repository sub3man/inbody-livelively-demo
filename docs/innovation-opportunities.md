# 혁신 기회 발굴

> 작성일 2026-06-13 · 맥락: 이 산출물은 "투자/제휴를 설득하는 피치 데모"다. 따라서 "혁신"의 KPI는 **설득력·신뢰도·공유성**이지, 일반 SaaS의 MAU/리텐션이 아니다.

각 아이디어는 요청 양식(문제·참고 OSS·구현·사용자가치·비즈니스가치·난이도·리스크·MVP·확장성)을 따른다.

---

## IDEA 1 — 인쇄/PDF 산출물 내보내기 ✅ (이번 작업에서 구현)

- **해결 문제**: "PDF 내보내기/결과보고서 내보내기" 버튼이 죽어 있어 피치 중 신뢰가 깨지고, 제안서를 메일/문서로 남길 방법이 없음.
- **참고 OSS**: paged.js의 `@page`·`break-inside` 패턴, reveal.js의 PDF export 모드(코드 미사용, 패턴만).
- **구현**: `@media print` 전용 스타일 + `printDoc()`(`window.print()`)로 **현재 탭만** 깔끔히 인쇄/PDF 저장. 의존성 0, 오프라인 동작, 기능 플래그(`FEATURES.printExport`)로 비활성화 가능.
- **사용자 가치**: 화면 = 인쇄물. 발표 후 즉시 PDF로 공유.
- **비즈니스 가치**: 제안 문서가 그대로 남아 의사결정자에게 재전달됨(브랜드 노출 반복).
- **난이도**: 낮음. **리스크**: 낮음(추가 의존성·서버 변경 없음).
- **MVP**: 4개 export 버튼 연결 + 인쇄 CSS. **확장**: html2pdf.js로 "버튼 한 번에 파일 다운로드"까지(후순위).

---

## IDEA 2 — "내 시나리오 공유 링크" (시뮬레이터 상태 직렬화)

- **해결 문제**: 위험도/임팩트 시뮬레이터로 만든 값이 새로고침하면 사라지고, 상대에게 "이 설정으로 보세요"를 못 보냄.
- **참고 OSS**: reveal.js 해시 라우팅, 일반 URLSearchParams 패턴.
- **구현**: 슬라이더 값을 `#ask?gu=20&pp=500&cy=6`처럼 쿼리로 직렬화/복원. 기존 `go()` 해시 라우팅에 얹음.
- **사용자 가치**: "서울 25개구 전면 확대" 같은 시나리오를 링크로 즉시 공유.
- **비즈니스 가치**: 영업 중 맞춤 수치 링크 → 설득력↑.
- **난이도**: 낮음~중. **리스크**: 낮음. **MVP**: 임팩트 시뮬레이터만. **확장**: 위험도 분류·탭 상태까지.

---

## IDEA 3 — 발표자 모드(풀스크린 슬라이드)

- **해결 문제**: 현장 발표 시 브라우저 UI·스크롤이 노출되어 산만.
- **참고 OSS**: reveal.js/impress.js 전환·풀스크린 UX(패턴 참고).
- **구현**: `F` 키로 Fullscreen API + 탭을 슬라이드처럼 좌우 전환(이미 방향키 내비 존재). 진행 점 표시.
- **사용자 가치/비즈니스 가치**: 키노트 수준 발표 경험 → 전문성 인상.
- **난이도**: 중. **리스크**: 중(모션/포커스 관리, reduced-motion 대응 필요). **MVP**: 풀스크린+진행표시. **확장**: 발표자 노트.

---

## IDEA 4 — 데이터 레이어 분리(멀티 데모)

- **해결 문제**: 자치구/대상자 수치가 마크업·JS에 하드코딩 → 다른 지자체용 데모를 만들 때 통째로 수정.
- **참고 OSS**: 정적 사이트의 JSON 데이터 패턴.
- **구현**: `clients[]`·KPI·지표를 `data/*.json`(또는 상단 단일 객체)으로 추출, 렌더 함수가 주입.
- **사용자 가치**: "○○구 버전" 데모를 데이터 교체만으로 생성.
- **난이도**: 중. **리스크**: 중(회귀 주의). **MVP**: 참여자/KPI만 분리. **확장**: 전 지표.

---

## IDEA 5 — 접근성·모션 배려 강화

- **해결 문제**: 키보드 사용자·스크린리더·모션 민감 사용자 배제(탭/표 행 키보드 미동작, `prefers-reduced-motion` 미대응).
- **참고 OSS**: axe-core 룰셋(검증용), focus-trap 패턴.
- **구현**: 탭 `role="tab"`/`tabindex`/Enter, 표 행 키보드 활성화, `@media (prefers-reduced-motion)`로 애니메이션 차단.
- **사용자 가치**: 공공(B2G) 맥락에서 접근성은 **신뢰·규정 적합** 신호.
- **난이도**: 낮음~중. **리스크**: 낮음. **MVP**: reduced-motion + 탭 키보드. **확장**: 전 인터랙션 ARIA.

---

## IDEA 6 — 오프라인 발표 번들

- **해결 문제**: Pretendard/Chart.js가 외부 CDN → 발표장 네트워크 단절 시 폰트·차트 붕괴.
- **참고 OSS**: 해당 라이브러리 배포본(로컬 동봉).
- **구현**: 폰트·Chart.js를 저장소에 동봉하고 상대경로 로드(라이선스 고지 동반). Chart.js는 현 init 구조상 `defer` 대신 동기 로드 유지 또는 init을 `load` 이벤트로 가드.
- **난이도**: 중(바이너리 동봉·고지). **리스크**: 중(로드 순서). **MVP**: 폰트만 로컬. **확장**: 전 자산.
